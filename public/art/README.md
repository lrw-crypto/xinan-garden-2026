# 草商輔導寺庭院美術

temple-courtyard.webp 為本專案生成的原創場景，以古典木構亭屋、青綠琉璃瓦、紅燈籠、櫻花、心願樹與錦鯉池為主題。未擷取或修改使用者參考截圖中的網站素材。

原始生成尺寸 1632 × 964，轉存為 WebP quality 88。Phaser 將背景繪製在 1000 × 590 邏輯座標上，人物、暱稱、狀態、互動標籤、花瓣與祝福星光為獨立即時圖層；背景不包含假在線人物。

透過 import.meta.env.BASE_URL 載入以支援 GitHub Pages 子路徑。
